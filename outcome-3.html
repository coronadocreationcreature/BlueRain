Learning outcome 03 · Search & strategy

Search, strategy, and adversarial reasoning.

Describe how core AI techniques such as search and adversarial reasoning are used to model intelligent behavior.

My reflection

AI search allows an agent to consider possible actions before choosing the best possible way to reach its goal from its current state. The situation an agent faces is determined by the environment and available decisions that it can make in its state. From its initial state the agent builds a search tree containing branches that represent the actions and resulting states that could result. In ordinary search the world is predictable and the agent doesn’t have to adapt based on another agent or a changing environment. This means the agent can consider options even further ahead using either Breadth-first search, depth-first search and A* search. Breadth-first explores all first step options to move away before deciding on an action to find the cheapest route however a downside to this method is that it might take a while as it will examine states that don’t help reach the final goal however it will evaluate all possible routes so it won’t miss any better options.

Depth-first search follows one route as far as it can then back tracks if the goal isn’t satisfied. This makes depth-first search quicker and more efficient for finding a route; however, it can miss out on better, more optimal future routes that it fails to evaluate if the goal is satisfied by a bad route at the start of the search. Another type of search is A* which helps an AI find a low-cost route by considering how much it has spent to get to its current state and how much farther it estimates the goal is from its state. Adding these amounts can help it to decide the best next action and explore the lowest score first. This allows the agent to consider both the distance it has travelled and the estimated distance to the finish using heuristics. A heuristic is what helps the AI to decide which actions to explore first. For example with A* the sum of the distance travelled and distance left to travel doesn’t give a guaranteed best route, it simply gives the agent a way to consider the better possibilities and forget about the useless ones.

Q-learning is another type of AI search which learns which actions work through trial and error. Each move it makes gives the previous state a Q-value that evaluates how well it helped the agent to reach its goal and it assigns these Q-values to each state, making different actions at each state until it finds the optimal route using the Q-values. Using these values it forms a policy which is its strategy for choosing actions which allows the agent to adapt when the environment changes due to its feedback.

For an agent going up against another agent however the case is different. Searching every possible response can take too much time which is why alpha-beta pruning helps minimax work more efficiently. As the agent searches the problem tree, it tracks the best possible option the MAX has found so far which is the alpha and the best possible option the MIN has found so far, the beta, and if a branch is guaranteed to be worse for MAX then the agent can avoid searching that branch. By pruning these branches, it reduces the amount of time required while keeping the same choice that minimaxing would after examining the branches. Using all of these; Ordinary search, heuristics, minimaxing and alpha beta pruning an agent can consider its actions, the environments affect and its opponents actions to choose the best possible actions and states to reach a goal.
